# 004.1: CLI Framework and Script Registry

Input: `intent/001_idea`, subdivided from `planning/004_cli_framework`

## Goal

Build the foundational CLI skeleton: the Click entry point, dry-run and config
global options, the script registry that links config entries to Python functions,
and the `run_command` shell helper. This is the layer that all script commands
plug into. Prompt dispatch and audit logging are handled in 004.2 and 004.3.

## Scope

- Click CLI group with `--dry-run` and `--config` global options
- Script registry (`register_script` decorator, `validate_registry`)
- `run_command` shell helper respecting dry-run mode
- `ConfigError` exception type
- Wiring prompt commands in at startup (calls into 004.2 once that is implemented)

## CLI structure

```python
@click.group()
@click.option("--dry-run", is_flag=True, help="Print commands without executing them.")
@click.option("--config", "config_path", type=click.Path(exists=True), help="Path to config file.")
@click.pass_context
def cli(ctx: click.Context, dry_run: bool, config_path: str | None) -> None:
    """Agentic workflow orchestration tool."""
    config = load_config(Path(config_path) if config_path else None)
    validate_registry(config)  # fail fast
    register_prompt_commands(cli, config)  # wired in by plan 004.2
    ctx.ensure_object(dict)
    ctx.obj["config"] = config
    ctx.obj["dry_run"] = dry_run
```

## Script registry

```python
class ConfigError(Exception):
    """Raised when the config is invalid (e.g. references an unknown script)."""

_SCRIPT_REGISTRY: dict[str, ScriptFunc] = {}

ScriptFunc = Callable[..., int]  # return code

def register_script(name: str) -> Callable[[ScriptFunc], ScriptFunc]:
    """Decorator to register a Python function as a named script."""
    def decorator(func: ScriptFunc) -> ScriptFunc:
        _SCRIPT_REGISTRY[name] = func
        return func
    return decorator

def validate_registry(config: WorkflowConfig) -> None:
    """Fail fast if config references a script name not in the registry."""
    for state_config in config.states.values():
        for cmd in state_config.commands:
            if isinstance(cmd, ScriptCommand) and cmd.script not in _SCRIPT_REGISTRY:
                raise ConfigError(f"Config references unknown script: {cmd.script!r}")
```

All script command modules must be imported before `validate_registry` is called.
Use a conventional block of imports at the top of `cli.py`:

```python
import workflow.commands.info      # noqa: F401  — registers info commands
import workflow.commands.workflow  # noqa: F401  — registers workflow commands
```

## Shell command execution

```python
def run_command(
    args: list[str],
    *,
    dry_run: bool = False,
    **kwargs: Any,
) -> subprocess.CompletedProcess[bytes] | None:
    """Run a shell command, or print it if dry_run is True.

    Passes **kwargs through to subprocess.run (e.g. cwd, env, capture_output).
    Raises subprocess.CalledProcessError on non-zero exit (check=True).
    """
    if dry_run:
        console.print(f"[dim]would run:[/dim] {shlex.join(args)}")
        return None
    return subprocess.run(args, check=True, **kwargs)
```

## Risks

- All command modules must be imported before `validate_registry` is called at
  CLI startup. A missing import silently skips validation for that module.
  Keep the import block in `cli.py` complete and documented.
- Until 004.2 is wired in, `register_prompt_commands` is a no-op stub.
  This is intentional; prompt commands simply won't appear in `--help` until 004.2
  is implemented. Do not try to call tmux before 004.2 is ready.

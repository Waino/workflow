# 004.2: Prompt Dispatch and Tmux Integration

Input: `intent/001_idea`, subdivided from `planning/004_cli_framework`

## Goal

Implement prompt command dispatch: dynamically register Click commands from the
YAML config, render Jinja2 prompt templates, optionally open the rendered prompt
in `$EDITOR` (`--edit` flag), and send the final text to the correct agent's tmux
window via libtmux. Replaces the no-op stub in `tmux_dispatch.py` left by plan 004.1.

## Scope

- Dynamic Click command registration from config (`register_prompt_commands`)
- Prompt template rendering with `{path_to_plan}`
- `--edit` flag: open rendered prompt in `$EDITOR`, cancel on empty file
- `send_prompt_to_agent`: locate tmux window, wait configured delay, send keys
- Mandatory pre-step: `git pull` in the agent's host-side repo before sending
- Audit log entry written after each successful dispatch
- `libtmux` added as a project dependency

## Dynamic command registration

```python
def register_prompt_commands(cli: click.Group, config: WorkflowConfig) -> None:
    """Dynamically register one Click command per distinct PromptCommand name.

    Commands with the same name in multiple states share a single CLI entry point.
    The correct prompt template is selected at dispatch time based on the resolved
    plan's current state.
    Multi-word names (e.g. 'full review') are exposed as kebab-case ('full-review').
    """
```

Each registered command signature:

```python
@cli.command(kebab_name)
@click.argument("plan_path", required=has_plan)
@click.option("--edit", "edit_mode", is_flag=True,
              help="Open rendered prompt in $EDITOR before sending.")
@click.pass_context
def _prompt_cmd(ctx: click.Context, plan_path: str | None, edit_mode: bool) -> None:
    ...
```

`has_plan` is `True` for all prompt commands that take a plan argument.
State-less commands (`full-review`, `followthrough`) set `has_plan=False`
and send to the configured agent for the relevant state directly.

## Dispatch sequence

For each prompt command invocation:

1. Resolve `plan_path` to a canonical `Plan` via `resolve_plan` (plan 003).
2. Look up the plan's current state in config; retrieve the matching `PromptCommand`.
   Raise a clear error if no command with that name exists in the plan's current state.
3. Determine the responsible agent from `config.states[plan.state].agent`.
4. Run mandatory pre-step: `git pull` in `{project_dir}/{agent_name}/` (plan 005).
5. Render the Jinja2 prompt template with `{path_to_plan}` = canonical path string.
6. If `--edit`: write rendered prompt to a `tempfile.NamedTemporaryFile` (suffix `.md`),
   open with `$EDITOR` (fall back to `vi`), wait for the editor process to exit,
   read back the file. If empty after stripping whitespace, print
   `"Cancelled (empty prompt)."` and exit without sending or logging.
7. Call `send_prompt_to_agent(agent_name, final_prompt, config, dry_run=dry_run)`.
8. Call `write_audit_log(config.project_dir, entry)` (plan 004.3).

## Tmux dispatch

```python
def send_prompt_to_agent(
    agent_name: str,
    prompt: str,
    config: WorkflowConfig,
    *,
    dry_run: bool = False,
) -> None:
    """Send a rendered prompt to the named agent's tmux window.

    Locates the tmux session by config.tmux.session_name.
    Finds the window whose name matches agent_name.
    Sleeps config.tmux.prompt_send_delay seconds before send_keys,
    giving the operator a moment to abort if the wrong window is focused.
    In dry-run mode, prints the target window and the full prompt instead of sending.
    """
```

Raises `WorkflowError` (not an unhandled exception) if:
- The tmux server is not running.
- The configured session does not exist.
- No window named `agent_name` exists in that session.

In all failure cases print a hint: `"Run 'workflow start' to create the tmux session."`

## Risks

- `send_keys` is fire-and-forget: the CLI cannot detect whether the agent is already
  busy. Document that the operator should only dispatch when the agent is at the prompt.
  The configurable delay (`prompt_send_delay`) gives a visible pause before keys are sent.
- The `--edit` flow depends on `$EDITOR` being set and working. Fall back to `vi` and
  document the fallback. If the editor exits with a non-zero code, treat as cancellation.
- Jinja2 template rendering can raise `UndefinedError` if a template variable is missing.
  Catch and surface as a `WorkflowError` with the variable name.
- `prompt dispatch → git_pull (plan 005) → run_command (plan 004.1)`: layered dependency,
  not circular — `tmux_dispatch.py` imports from `git_helpers.py` and `shell.py` but
  neither of those imports from `tmux_dispatch.py`.
